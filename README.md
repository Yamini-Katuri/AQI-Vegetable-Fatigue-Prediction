# AQI, Fatigue & Vegetable Price Prediction

This project predicts **human fatigue** and **vegetable prices (tomato & onion)** based on **AQI, humidity, and temperature** using Python and machine learning.

## Features

- Data analysis and descriptive statistics
- Correlation heatmaps
- Trend analysis over time
- Linear Regression models for:
  - Fatigue
  - Tomato Price
  - Onion Price
- Interactive input for custom predictions
- 7-day forecast visualization
- Clean, multi-axis plots for better visualization

## Dataset

- The dataset (`final_data.csv`) contains 30 rows with columns:
  - Date
  - AQI
  - Humidity
  - Temperature
  - TomatoPrice
  - OnionPrice
  - Fatigue
